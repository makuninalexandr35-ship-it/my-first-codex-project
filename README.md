# LUMÉ — учебный лендинг кондитерской

Современный адаптивный одностраничный сайт вымышленной московской кондитерской **LUMÉ**. Проект создан без фреймворков и сторонних зависимостей — только HTML, CSS и JavaScript.

## Структура проекта

```text
.
├── index.html   # разметка, секции и форма заказа
├── styles.css   # дизайн, адаптивность и анимации
├── script.js    # мобильное меню, форма и интерактивные элементы
└── README.md    # документация проекта
```

## Как запустить

Откройте `index.html` двойным щелчком или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем перейдите по адресу [http://localhost:8000](http://localhost:8000).

## Что реализовано

- главный экран с ключевым предложением;
- каталог авторских тортов;
- блоки «О нас» и «Почему мы»;
- адаптивная навигация для телефона;
- форма заказа с базовой проверкой полей;
- плавная прокрутка, анимация появления блоков и динамический год;
- адаптивная вёрстка для мобильных и настольных экранов.

> Форма работает в демонстрационном режиме и не отправляет данные на сервер.
